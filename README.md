A Python-based application designed to help users manage their personal finances effectively. This app allows users to track spending across various categories such as food, transportation, and miscellaneous expenses.

User inputs are gathered through the terminal, and you can click on the screen to proceed to the next question.

Key features include automatic output generation based on your spending in various categories. All graphics in the application are hand-drawn. Additionally, the program displays randomized tips at the bottom of the screen to assist users throughout their experience.
