This Python-based financial app that helps users manage their personal finances by getting user spending on various aspects like food, transportaion, miscellaneous, and other things.

The Inputs are read from the terminal, and you click on screen to go to the next question. 

Some of the featurs are that the code automatically gives output based on how much you are spending on a certain thing. All the drawing in the code were hand drawn. 
Throughout the program there are randomized tips running at the bottom for the user.
